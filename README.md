# AVA 1.1.1 Calendar Update

New:
- “+ Termin” button directly in the calendar
- Create ordinary personal/internal appointments without a customer
- Optionally link a customer/prospect
- Title, date/time, duration, appointment type and notes
- AVA checks calendar conflicts before saving
- Voice examples:
  - “Termin morgen um 10 Uhr: Teammeeting”
  - “Termin mit Max Mustermann Freitag um 15 Uhr”
- Manual appointments appear in day/week calendar and Today when applicable
- Existing AVA 1.1 futuristic dark design and full Sales Assistant functionality retained

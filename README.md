# AVA Alpha 0.8

Assistant workflow update.

- iPhone/mobile microphone is explicitly stopped and released after each recognition cycle or when closing AVA Voice
- Mobile weekly calendar shows days vertically instead of horizontal columns
- Prospects no longer require a customer number
- When status changes to ordered/customer, AVA requires a customer number
- Added purchased vehicle separate from vehicle interest
- Voice can create a new prospect and schedule a test drive in one command
- Voice checks local duplicate candidates before creating a prospect
- Customer history is hidden behind a dedicated History button inside the customer record
- Test-drive cancellation uses synchronized cancellation logic and cancels open test-drive reminder/follow-up tasks

Use fictional test data only during alpha.
